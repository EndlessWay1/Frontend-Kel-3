## Daftar Tugas

### Tugas 1: Parabolic Prediction

Gerak parabola merupakan salah satu konsep dalam fisika yang menggunakan perhitungan matematis.

Perubahan kecepatan, sudut, dan gravitasi dapat memengaruhi lintasan objek.

Perhitungan secara manual membuat perubahan lintasan lebih sulit untuk dibayangkan

Oleh karena itu, dibuat simulasi interaktif untuk membantu melihat perubahan gerak parabola secara langsung.
